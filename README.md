# MiVue Vuer

Windows向けのMiVueドライブレコーダー閲覧アプリです。Electronを使い、Windowsデスクトップ上で動画を表示しながら、Node.js側でSDカードの読み取り・ファイル検証を行います。動画再生はChromium、映像のブラウザー互換化とトリミングはFFmpegを使用します。

## 開発環境で起動

1. Node.js 20以降をインストールします。
2. このフォルダーで `npm install` を実行します。
3. `npm start` で起動します。
4. 「録画フォルダーを開く」から、`Event`、`Normal`、`Triplapse`、`DEVICE.XML`が入っているフォルダーを選びます。

このプロジェクトはWindows用Electronアプリです。配布用インストーラーはまだ設定していません。依存パッケージにFFmpeg/FFprobe実行ファイルを含めています。

## 操作

- プレイバック・走行データ・走行ルートの「別ウィンドウ ↗」で、そのビューを元画面から切り離して拡大表示できます。別ウィンドウはサイズ変更・最大化でき、動画操作・再生位置・グラフ・地図は同じ状態を維持します。「元の画面へ戻す」またはウィンドウを閉じる操作で元の位置に戻ります。元画面を閉じると別ウィンドウも閉じます。
  - プレイバックを元画面へ戻す際は、現在位置から動画を再準備するため一時的に停止します。再生中だった場合は自動で再開し、一時停止中だった場合は停止状態を維持します。
- 録画ライブラリは常時表示します。検索条件だけを初期状態で折りたたみ、ライブラリ内の「検索条件を表示」「検索条件を閉じる」で開閉します。閉じても検索条件は維持されます。トリミングは初期状態では非表示で、画面上部の「トリミング」で開閉できます。どちらも再生を止めずに開閉でき、入力内容は保持されます。「SDカードをコピー」は画面上部から開けます。エラー・進行状況の通知は常時表示します。
- 日付範囲、録画カテゴリー、カメラ、GPSの有無で録画を絞り込みます。
- フォルダーを開くと検索結果の最初の録画を自動再生します。一覧で録画を選択した場合も、再生ボタンなしで前後映像の同期再生を開始します。停止する場合は一時停止してください。再生中に次の録画へ進むと、空白区間をタイムラインに示し、その区間の映像を補間せず次のファイルへ移ります。
- 再生中に検索結果の次の前後動画を先読みし、終了時に読み込み済みの動画へ自動で切り替えます。動画の結合操作は不要で、元ファイルは変更しません。先読み完了後は変換・読み込み待ちを挟まず切り替えますが、ディスク速度などにより先読みが間に合わない場合は準備待ちとなります。録画のない時間はスキップし、空白の長さを表示します。完全なフレーム単位・音声サンプル単位のギャップレス再生を保証するものではありません。
- 先読みが完了していれば、終端の約0.1秒前から次の前後映像を先行再生し、前方カメラの音声をクロスフェードします。短時間だけ前後の音が重なり、映像の切り替え時には次の動画の先行再生分が進んだ状態になります。元ファイルは変更せず、一時停止・シーク・録画選択の変更時はクロスフェードを中止します。ミュートは両方の音声に適用します。元録画に含まれる無音や音声欠落を復元する機能ではありません。先読みが間に合わない場合は通常の自動切り替えになります。
- GPSが有効なRMC行があれば、速度・位置・高度・ルートを再生時刻に合わせて表示します。
- 地図の経路軌跡と自車位置は同じ青色で表示します。自車位置は白い縁取り付きの三角形で、先端がGPSの進行方位（北が0度、東が90度）を示します。方位が不明・無効な場合は青い丸で表示します。GPSの進行方位は車体の向きとは異なり、停車中・低速時は不安定になる場合があります。
- 走行データ欄の速度グラフの下にXYZのGグラフを表示します。欄内を下にスクロールすると確認できます。Xは水色、Yは黄色、Zは紫で、再生位置カーソルと現在値を表示し、シーク・自動切り替えにも追従します。データがない時刻は `--` と表示します。
- G値はMiVue独自の `$GSENSORD` の先頭3数値をX/Y/Zとして表示します。角括弧内の別の3数値は使用しません。独自形式のため軸の物理方向・較正や重力除去の仕様は未確認です。GPSが無効でも、RMCの時計の先頭からの経過秒で映像先頭に合わせて表示します（時計と動画の開始ずれがある場合は同じずれが残ります）。日付が未確定のGPSでも表示でき、読み取れないセンサー行は読み込み警告として通知します。
- トリミングでは開始・終了を秒数で指定します。標準は映像を再エンコードしない高速切り出し（開始位置がキーフレームに合わせて前後する場合があります）で、MP4互換性のため音声はAACに変換します。正確な開始位置を優先する場合はH.264 CRF 18/AACで再エンコードします。元ファイルは変更しません。
- 「SDカードをコピー」からコピー元・先と対象カテゴリーを指定します。コピー中断時に残る `.partial` ファイルを次回に再利用し、完成後にSHA-256を照合します。元データは削除しません。

## データと時刻

- `Data`などの親フォルダー名は任意です。選択したフォルダーの直下に、機器が作成した `Event`、`Normal`、`Triplapse`、`DEVICE.XML` がある構成として扱います。`DEVICE.XML` はフォルダーではなくファイルです。
- 対象パス: 選択した親フォルダー直下の `Normal`、`Event`、`Triplapse` 以下にある `F`、`R`、`NMEA`。
- SDカードから読み込む場合は、`Event`、`Normal`、`Triplapse`、`DEVICE.XML`の親フォルダーを選択してください。フォルダー名が `Data` である必要はありません。
- 現在認識するファイル名: `FILE` / `EMER` / `TRIP` + `YYMMDD-HHMMSS` + カメラ記号。
- ファイル名の時刻はJSTとして扱います。NMEA RMCの日時・時刻はUTCとして解析し、時刻照合にはUTCの実時刻を使い、画面上はJSTで表示します。
- MP4の再生準備では、一時フォルダーに映像ストリームをコピーし、音声をAACへ変換して、カメラ固有のデータストリームは除外します。一時ファイルにも `.mp4` 拡張子を付けて出力形式を明示します。入力動画の映像コーデックがChromiumと非互換の場合は再生できない場合があります。
- オンライン地図はOpenStreetMapのタイルを使用します。地図表示にはインターネット接続が必要です。OpenStreetMapの利用ポリシー・帰属表示を遵守してください。
- 現段階の検索は読み込み済みファイル一覧に対する日時・カテゴリー・存在条件の絞り込みです。ファイル内のタイムコードによる時刻補正は未実装です。

## トラブルシューティングと制約

- 録画が見つからない場合は、選択した場所の直下に `Event`、`Normal`、`Triplapse` のいずれかがあること、カテゴリー配下に `F` / `R` / `NMEA` があることを確認します。親フォルダー名は任意です。認識できないファイル名や読み取りエラーは画面に警告されます。
- 動画を開けない場合は、元ファイルが再生可能であること、ドライブにアクセスできることを確認してから再読み込みしてください。ブラウザー互換用ファイルはWindowsの一時フォルダーに作られます。
- 動画は最初のフレームを読み込んでから表示します。読み込み失敗時はカメラ・ファイル名・メディアエラーの詳細を画面下部に表示します。録画を切り替えた際は古い読み込みの画面更新を中止し、映像を覆う待機表示も解除します。前後の同期を維持するため、ウィンドウがバックグラウンドにある場合も再生を継続します。停止したい場合は一時停止してください。
- GPSがない区間からGPS付きの録画へ切り替わる際も、地図の中心とズームを初期化して自動再生を継続します。対応するGPSがない時刻には、前の録画の位置を引き継いで表示しません。
- コピーに失敗した場合は表示されたファイル名とエラーを確認してください。同名で内容の異なるコピー先ファイルは上書きしません。`.partial` ファイルが残っている場合、同じコピー先を選ぶと続きから再開します。
- 速いトリミングはキーフレーム境界に制限されます。開始位置を厳密に指定する場合は「開始位置を優先」を選択します（映像を再エンコードするため時間がかかります）。
- 配布用インストーラー、オフライン地図、録画内タイムコードによる時刻補正は未実装です。

## テスト

`npm test` でファイル名・GPS解析、カメラ対応付け、コピー再開とSHA-256検証のテストを実行します。

`npm run test:playback` は実際のElectronウィンドウでサンプルの前後動画を開き、デコードされたフレームと待機表示の解除を確認して終了します。既定の入力はプロジェクト内の `Data` です。別の録画フォルダーは `npm run test:playback -- "D:\録画"` のように指定できます。

この再生テストでは次の録画を先読みし、終端からの自動切り替え、前後同期、一時停止も検証します。先読み完了時の次フレーム表示までの遅延が250ミリ秒未満であることを確認します（環境に依存します）。
