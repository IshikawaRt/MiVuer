# MiVue Vuer

Windows向けのMiVueドライブレコーダー閲覧アプリです。Electronを使い、Windowsデスクトップ上で動画を表示しながら、Node.js側でSDカードの読み取り・ファイル検証を行います。動画再生はChromium、映像のブラウザー互換化とトリミングはFFmpegを使用します。

## 開発環境で起動

1. Node.js 20以降をインストールします。
2. このフォルダーで `npm install` を実行します。
3. `npm start` で起動します。
4. 「録画フォルダーを開く」から、`Event`、`Normal`、`Triplapse`、`DEVICE.XML`が入っているフォルダーを選びます。

このプロジェクトはWindows用Electronアプリです。配布用インストーラーはまだ設定していません。依存パッケージにFFmpeg/FFprobe実行ファイルを含めています。

## 操作

- 日付範囲、録画カテゴリー、カメラ、GPSの有無で録画を絞り込みます。
- 一覧で録画を選択すると前後映像が同期して開きます。再生中に次の録画へ進むと、空白区間をタイムラインに示し、その区間の映像を補間せず次のファイルへ移ります。
- GPSが有効なRMC行があれば、速度・位置・高度・ルートを再生時刻に合わせて表示します。
- トリミングでは開始・終了を秒数で指定します。標準は映像を再エンコードしない高速切り出し（開始位置がキーフレームに合わせて前後する場合があります）で、MP4互換性のため音声はAACに変換します。正確な開始位置を優先する場合はH.264 CRF 18/AACで再エンコードします。元ファイルは変更しません。
- 「SDカードをコピー」からコピー元・先と対象カテゴリーを指定します。コピー中断時に残る `.partial` ファイルを次回に再利用し、完成後にSHA-256を照合します。元データは削除しません。

## データと時刻

- `Data`などの親フォルダー名は任意です。選択したフォルダーの直下に、機器が作成した `Event`、`Normal`、`Triplapse`、`DEVICE.XML` がある構成として扱います。`DEVICE.XML` はフォルダーではなくファイルです。
- 対象パス: 選択した親フォルダー直下の `Normal`、`Event`、`Triplapse` 以下にある `F`、`R`、`NMEA`。
- SDカードから読み込む場合は、`Event`、`Normal`、`Triplapse`、`DEVICE.XML`の親フォルダーを選択してください。フォルダー名が `Data` である必要はありません。
- 現在認識するファイル名: `FILE` / `EMER` / `TRIP` + `YYMMDD-HHMMSS` + カメラ記号。
- ファイル名の時刻はJSTとして扱います。NMEA RMCの日時・時刻はUTCとして解析し、時刻照合にはUTCの実時刻を使い、画面上はJSTで表示します。
- MP4の再生準備では、一時フォルダーに映像ストリームをコピーし、音声をAACへ変換して、カメラ固有のデータストリームは除外します。一時ファイルにも `.mp4` 拡張子を付けて出力形式を明示します。入力動画の映像コーデックがChromiumと非互換の場合は再生できない場合があります。
- オンライン地図はOpenStreetMapのタイルを使用します。地図表示にはインターネット接続が必要です。OpenStreetMapの利用ポリシー・帰属表示を遵守してください。
- 現段階の検索は読み込み済みファイル一覧に対する日時・カテゴリー・存在条件の絞り込みです。ファイル内のタイムコードによる時刻補正は未実装です。

## トラブルシューティングと制約

- 録画が見つからない場合は、選択した場所の直下に `Event`、`Normal`、`Triplapse` のいずれかがあること、カテゴリー配下に `F` / `R` / `NMEA` があることを確認します。親フォルダー名は任意です。認識できないファイル名や読み取りエラーは画面に警告されます。
- 動画を開けない場合は、元ファイルが再生可能であること、ドライブにアクセスできることを確認してから再読み込みしてください。ブラウザー互換用ファイルはWindowsの一時フォルダーに作られます。
- コピーに失敗した場合は表示されたファイル名とエラーを確認してください。同名で内容の異なるコピー先ファイルは上書きしません。`.partial` ファイルが残っている場合、同じコピー先を選ぶと続きから再開します。
- 速いトリミングはキーフレーム境界に制限されます。開始位置を厳密に指定する場合は「開始位置を優先」を選択します（映像を再エンコードするため時間がかかります）。
- 配布用インストーラー、オフライン地図、録画内タイムコードによる時刻補正は未実装です。

## テスト

`npm test` でファイル名・GPS解析、カメラ対応付け、コピー再開とSHA-256検証のテストを実行します。
